# React => A JavaScript Library

=> React is a powerful JavaScript library for building fast, scalable front-end applications. Created by Facebook, it's known for its component-based structure, single-page applications (SPAs) and virtual DOM, enabling efficient UI updates and a semaless user experience.
=> makes easy to manage and build complex frontend
=> Virtual DOM is a lightweight JavaScript representation kept in memory to calculate minimal updates before touching the screen.

### Library vs Framework

- Library: You can structure your project layout however you prefer. You call the library. YOu decide when, where, and how to use it.
- Framework: You must follow its strict rules, naming conventions, and file structures. The framework calls your code. It dictates the overall application flow.

## Importance of React:

- Manual DOM Manipulation
- Complex State Management
- Tight Coupling in Frameworks
